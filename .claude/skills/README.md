# Skills

`hegel/` and `hegel-review/` are copied unchanged from [hegeldev/hegel-skill](https://github.com/hegeldev/hegel-skill) at commit `a60b282` (MIT; each directory has the licence). They guide writing and reviewing property-based tests with [Hegel](https://hegel.dev), the Hypothesis team's property-based testing library, and apply to Hypothesis too. To update them, copy the two directories from a newer commit after reading the diff, and change the commit here.

Instead of this copy, you can install them as a plugin: `/plugin marketplace add hegeldev/hegel-skill`, then `/plugin install hegel-skill@hegeldev`.
