# Proposals to other projects

These drafts are parked, not posted. Do not refresh them on each protocol or ecosystem change. The repository is public; no publication prerequisite remains.

| Draft | Request |
| --- | --- |
| [OpenClaw](openclaw-poppy.md) | An optional Poppy plugin, with a human approval path |
| [Hermes](hermes-agent-poppy.md) | A standalone Poppy plugin and any missing credential/identity seams |
| [Spec feedback](poppy-feedback.md) | A small batch of editorial interoperability fixes, ready for owner review |

Immediately before submitting a plugin proposal, verify its proposed host APIs and search for an existing proposal. Add one relevant result from [current verification](../poppy-0.3-conformance.md#current-verification); link to the [ecosystem observations](../ecosystem.md#current-ecosystem) rather than copying counts. The [deployment checklist](../deployment-tasks.md#3-then) records the owner's live-verification prerequisite. Historical implementation research is linked from each draft and is not a promise that those APIs still exist.

Owner approval is required before an external post or email ([SECURITY.md](../../SECURITY.md), disclosure rule 6). Security findings stay in the separate private disclosure process. Preparing these drafts does not authorize sending them.
