# Poppy 0.3: the ledger

> PDA dropped 0.3 on 12 November 2026 ([decision 49](decisions.md#49-03-dropped-the-agent-mock-validator-and-interop-speak-04-alone)). This ledger is kept as 0.3's record; its links go to the files at the last main commit before 0.4. The current ledger is [0.4's](poppy-0.4-upgrade.md#the-11-november-changelog-entry-by-entry).

We speak 0.3 alone, with the manually reviewed [3 November 2026 snapshot](../spec/draft-0.3-retrieved-2026-11-03/README.md); 0.1 and 0.2 remain refused ([decision 37](decisions.md)). The pin in [spec/upstream.json](../spec/upstream.json) records the site hashes and upstream commit `7205250`, whose specification, extension, guides and changelog text the snapshot matches apart from site formatting. `npm run check:spec` checks integrity offline; `npm run spec:drift` compares the pinned text with the live site on demand. The [29 October snapshot](../spec/draft-0.3-retrieved-2026-10-29/README.md) stays as a record.

Since the 29 October pin, upstream's 30 October and 2 November changes made these changes on the wire, all implemented:
- **Companies without an OAuth issuer.** A 404 for the protected resource metadata, or no authorization servers, means no issuer. The Company is then signed-out only, identified by `https://{organization.domain}`.
- **`auth.disabled`.**
- **Extension content in messages.** Operations 2's conversation approval moved to `extensions.operations`.
- **`session_ended`.** It is now separate from `invalid_session`, which is no longer retried.
- **New delegation names:** `poppy-delegation+jwt` and `poppy_dlg`.

The other entries relax rules (`scopes_supported` and `PS384` are now SHOULDs, and domains sharing an issuer can describe scopes differently), clarify existing text, or add optional features. PDA follows the recommended Web Bot Auth operator signatures when a deployment sets an operator key, accepts Company-first Direct Conversations, and shows Company logos. It doesn't use UCP, Links, Disclosures or skill indexes. It speaks MCP 2026-07-28's stateless lifecycle beside 2025-06-18's, choosing by what each server speaks ([readings](readings.md#mcp-lifecycle)).

## The 3 November changelog, entry by entry

The 0.3 changelog has 79 entries. [spec/requirements-0.3.json](../spec/requirements-0.3.json) gives each a disposition, implementation, evidence and limits. `npm run check:spec` requires an ordered entry for every title and verifies this generated table (`npm run spec:docs`).

"Done" records implementation of that entry, not full specification or Guides conformance. [Appendix A](../pda-spec.md#appendix-a-personal-agent-requirements) tracks individual requirements. The [conformance review](poppy-0.3-conformance.md) records current verification; the separate [upstream audit](poppy-0.3-issues.md) retains the problems found in the 28 October text, some of which the later text settles. Missing scope hints still use our documented Guides-based reading, not a specification MUST.
