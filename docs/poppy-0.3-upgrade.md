# Poppy 0.3: the ledger

We speak 0.3 alone, with the manually reviewed [29 October 2026 snapshot](../spec/draft-0.3-retrieved-2026-10-29/README.md); 0.1 and 0.2 remain refused ([decision 37](decisions.md)). The pin in [spec/upstream.json](../spec/upstream.json) records the site hashes; `commit` remains null because the restored browser rule is not yet in the upstream repository. `npm run check:spec` checks integrity offline; `npm run spec:drift` compares the pinned text with the live site on demand.

The only normative addition since the 28 October pin restores section 6's rule that only an agent-controlled browser may join a Session. PDA already uses its own per-User/Session browser context; a direct regression now checks that an ordinary User visit remains unjoined and join material stays out of visible output. No wire format changed. The earlier snapshot remains immutable.

## The 29 October changelog, entry by entry

The 0.3 changelog has 43 entries. [spec/requirements-0.3.json](../spec/requirements-0.3.json) gives each a disposition, implementation, evidence and limits. `npm run check:spec` requires an ordered entry for every title and verifies this generated table (`npm run spec:docs`).

"Done" records implementation of that entry, not full specification or Guides conformance. [Appendix A](../pda-spec.md#appendix-a-personal-agent-requirements) tracks individual requirements. The [conformance review](poppy-0.3-conformance.md) records current verification; the separate [upstream audit](poppy-0.3-issues.md) retains the problems found in the 28 October text. Missing scope hints still use our documented Guides-based reading, not a specification MUST.
