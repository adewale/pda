# Poppy implementations

Every public implementation of [Poppy, the Personal Agent Protocol](https://personalagentprotocol.org/) (Draft 0.1) we could find on **11 October 2026**, five days after Sierra and Meta announced it and two days after the draft was published. Everything listed is at most a few days old, so "last commit" is nearly always today.

**Method.** Read-only. GitHub search for repositories, code (`well-known/poppy`, `personalagentprotocol`, `poppy_domains`, `poppy:write`, `browser_session_endpoint`, `PoppyClient`, `poppy-client`, `poppy-agent`, "Personal Agent Protocol"), issues and pull requests created since 1 October; npm, PyPI and crates.io; web search; the two community lists ([awesome-poppy](https://github.com/JaviChulvi/awesome-poppy), [poppy.md/implementations](https://poppy.md/implementations)). One `GET /.well-known/poppy.json` per domain: a bare-domain redirect to `www.` was followed once. Documents that came back were checked offline with our validator (`npm run validate -- --kind poppy --domain <d> <file>`). That checks only the document itself, not the issuer's OAuth metadata. Nothing was posted, starred or forked.

## Not found

- **Agent frameworks:** we found no Poppy issue, PR or proposal in OpenClaw, Hermes Agent (Nous Research), cloudflare/agents, Letta, openai-agents-python, AutoGen, LangGraph, browser-use or Claude Code. OpenAgents is the only framework that has had one (closed, not planned).
- **Package registries:** only `@datalayer/personal-agent-protocol` / `personal-agent-protocol` (npm, PyPI), `poppyseed` (npm) and the adonis-agora packages. Nothing on crates.io.
- **Partners:** none serves a poppy.json. sierra.ai, personalagentprotocol.org, www.shopify.com, stripe.com, www.walmart.com, www.genesys.com, www.redfin.com and www.meta.com return 404; rocket.com returns 403; everruns.com and openagents.com return 404.
- **Live Companies (5):** Spot, withpoppyseed.dev, poppy.ilmer.org, poppy-receiver.roundtrip.workers.dev, plus the TYPO3 lab behind its login. Only Spot is a product; the others are demos or a small archive site.
