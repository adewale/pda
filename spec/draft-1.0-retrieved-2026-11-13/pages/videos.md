# Video tutorials

Short videos on how Personal Agent Protocol works, each a few minutes long. Start with the first, then watch the others in any order. The videos can lag behind the latest version, so the [specification](/docs/1.0/spec) should always be considered the source of truth.

## What is the Personal Agent Protocol?

What is the Personal Agent Protocol (also known as "Poppy"), and why do we need one? This video introduces Poppy and gives a high-level overview of how it works.

[Watch the video](https://personalagentprotocol.org/docs/videos#overview)

## Just the basics

There are many features that the Personal Agent Protocol supports, but what should you do if you just want to provide a basic level of support? Let's find out.

[Watch the video](https://personalagentprotocol.org/docs/videos#basics)

## Connecting your agent

How does a personal agent connect to a company for the first time? This video explains how an agent finds what communication methods a company supports, proves who it is, and starts a session.

[Watch the video](https://personalagentprotocol.org/docs/videos#connecting)

## Direct sign-in

You sign in on the company's own site, and your agent never sees your password. This video walks through Direct Sign-In, where users sign in themselves and authorize an agent to perform actions on their behalf.

[Watch the video](https://personalagentprotocol.org/docs/videos#direct-sign-in)

## Device sign-in

How can your users sign in if your agent doesn't have a browser available? This video explains Device Sign-In, where a personal agent passes along a QR code to the user, who can then sign in and authorize an agent from their phone.

[Watch the video](https://personalagentprotocol.org/docs/videos#device-sign-in)

## Agent-to-agent conversations

Personal agents can work with company agents to quickly perform actions and fix problems on behalf of their users. This video covers how they exchange messages, how an agent keeps up with replies, and when it needs to check back with the user.

[Watch the video](https://personalagentprotocol.org/docs/videos#conversations)

## Agent-to-MCP communication

Personal agents can communicate with MCP servers that companies may have already set up to work with AI tools. This video explains how that connection is established and how communication works.

[Watch the video](https://personalagentprotocol.org/docs/videos#mcp)

## Agent-to-website browsing

Some companies may not have agents, API endpoints, or MCP servers for a personal agent to talk to, but almost all of them have a website. Let's find out how an agent can browse a website on behalf of a user in this video.

[Watch the video](https://personalagentprotocol.org/docs/videos#browsing)
