Path to 1.0

How we get there

  • Anyone can implement it. Build against it, as a personal agent or a company, and send us feedback on what you run into.
  • We're implementing it with design partners. The spec's authors are working through implementations with several of the design partners.
  • The spec changes based on what we learn. From the release candidate on, changes before 1.0 are fixes, made in a draft 1.0, not new features. A fix can still break compatibility with earlier versions.

Providing feedback

Feedback is welcome from anyone, whether or not you're a partner.

Give feedback by opening an issue on GitHub, or by commenting on an existing issue for a roadmap topic. Feedback you send is licensed under the contribution terms.

Two tools can help you write it:

Review with an agent. If you'd like an agent to review the docs, give it the implementation kit, which includes all the docs. Paste the agent's review into your issue.

Use the site's inline comments. You can comment on any text on this site, then export your comments to share them. Enable site commenting, then select text to comment on it. To export, use the … button next to Comments, and paste or attach the export in your issue.

Roadmap

The roadmap lists the areas we expect to work on before 1.0, including the ones the spec doesn't cover yet, such as payments, push notifications, and attachments.
